# 清掃費の請求 — 設定手順

清掃スタッフが専用URLから勤務日ごとに入力し、月末に請求日を入れて請求するツールです。
入力内容は Googleスプレッドシートに保存され、請求書は PDF・画像で保存できます。

- **画面**: `index.html`（GitHub Pages で公開）
- **保存先**: Googleスプレッドシート ＋ `Code.gs`（Apps Script）

民泊用の Googleアカウント（tamura@easyllc.jp）で作業するのがおすすめです。

---

## 1. スプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`清掃費の請求`）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付けて保存（Ctrl+S）

## 2. 初期設定を実行する

1. スプレッドシートを再読み込みすると、メニューに **「清掃請求」** が出ます
2. **清掃請求 → ① 初期設定（最初に1回）** を実行
3. 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します
   （「このアプリは確認されていません」と出たら「詳細 → 安全ではないページに移動」で進めます。自分で作ったスクリプトなので問題ありません）
4. 「スタッフ」「記録」「請求」「設定」の4つのシートができます

## 3. ウェブアプリとして公開する

1. Apps Script の画面で、右上の **デプロイ → 新しいデプロイ**
2. 種類の歯車から **ウェブアプリ** を選ぶ
3. 次のように設定して「デプロイ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> 「全員」にしても、スプレッドシート自体は公開されません。専用のトークンを持っている人だけが、自分の記録を読み書きできます。

## 4. GitHub Pages のURL

この画面は清掃チェックリストと同じリポジトリ（`yoshinocho-cleaning`）の `invoice` フォルダに入っています。
URLは次のとおりです（チェックリストと同じ GitHub Pages で公開されます）。

`https://glow2021yoko.github.io/yoshinocho-cleaning/invoice/`

## 5. 画面とスプレッドシートをつなぐ

1. `index.html` の上の方にある次の1行を探して、手順3でコピーしたURLに書き換える
   ```js
   const API_URL = "ここにApps ScriptのウェブアプリURLを貼る";
   ```
2. GitHub 上で `invoice/index.html` を開き、鉛筆アイコンで編集して保存（Commit changes）
3. スプレッドシートの **「設定」シート** に入力
   - **宛名**：請求書の宛名（例：`〇〇合同会社 御中`）
   - **ページURL**：`https://glow2021yoko.github.io/yoshinocho-cleaning/invoice/`

## 6. スタッフを追加する

1. **清掃請求 → スタッフを追加してURLを発行** で名前を入れる
2. 表示された専用URLを、そのスタッフに LINE で送る
3. スタッフは最初に名前と振込先口座を登録してから、勤務日を入力します

URLをもう一度見たいときは **清掃請求 → スタッフのURLを再表示**。

## 7. 管理画面

**清掃請求 → 管理画面のURLを表示** で出るURLが、リサさん専用の管理画面です。

- 月ごと・スタッフごとの合計、請求日、未払い額
- 支払済の切り替え（スプレッドシートの「記録」シートの「支払」にチェックを入れても同じです）
- 請求書の PDF・画像の保存、CSVのコピー
- 請求書の宛名の変更

このURLは他の人に渡さないでください。

---

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| スタッフが辞めた | 「スタッフ」シートの「有効」のチェックを外すと、その人のURLが使えなくなります（記録は残ります） |
| URLが他の人に漏れた | 「有効」を外して、**スタッフを追加** で新しいURLを発行し直します |
| Code.gs を書き換えた | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ**。URLは変わりません |
| 「まだ準備中です」と出る | 手順5の `API_URL` が書き換わっていません |
| 物件を増やしたい | `invoice/index.html` の物件の選択肢と、`Code.gs` の `PROPERTIES` の両方に追加します |

### 注意

- 「スタッフ」シートには口座情報が入ります。スプレッドシートは他の人と共有しないでください。
- 管理者URLやスタッフのURLに入っている文字列（トークン）が、パスワードの代わりです。
